# Schiwyair Wartungszentrale (WordPress-Plugin)

Update-Pakete für das Plugin „Schiwyair Wartungszentrale" der Schiwyair GmbH.

Das Plugin verbindet eine WordPress-Website mit der Wartungszentrale der Agentur. Es wird nur auf Websites eingesetzt, die die Schiwyair GmbH betreut.

- `update.json`: Beschreibung der neuesten Version, mit Ed25519 unterschrieben
- `releases/`: die Pakete

Installierte Plugins prüfen die Unterschrift und die Prüfsumme und installieren nur Pakete der Schiwyair GmbH.

Aktuelle Version: **0.6.0**
